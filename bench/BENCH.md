## Index plan (as reported by the auditor)

- versions(version_id) UNIQUE          -- resolve version ids
- versions(key, commit_pos)            -- visible-version and successor probes, per-key chains
- versions(commit_pos)                 -- log-range completeness checks
- aborted_versions(version_id)         -- aborted-version attribution
- txns(txn_id)                         -- transaction records
- ops(txn_id, seq)                     -- per-transaction operation replay
- ops(key) WHERE type='point_read'     -- point-read lookup by key
- edges(src,dst), edges(dst,src)       -- adjacency streaming for SCC/topo

## Notes

- `edge_candidates` counts the indexed visible/successor version probes issued for reads (2 per key touched by a read); `range_keys_scanned` counts versioned keys visited inside scanned intervals - intervals are never expanded over the int64 domain.
- `realtime_edges` are emitted by a sorted sweep (O(n log n) candidate comparisons), not an n x n scan.
- skew configs inject write-skew pairs; the auditor reports `invalid` with a verified cycle witness.
